Kinetix - Интеллектуальный генератор 3D-моделей для Autodesk Inventor 2025

ОПИСАНИЕ
Kinetix - это приложение для автоматического создания трехмерных твердотельных деталей в Autodesk Inventor 2025 на основе текстовых промптов и 2D-чертежей (чертежи в форматах PDF, DWG, DXF, PNG, JPG).
Система поддерживает работу как с полностью локальными нейросетями через LM Studio, так и с облачными моделями Google Gemini.

ВОЗМОЖНОСТИ
- Двусторонняя интеграция с Autodesk Inventor 2025 через официальный COM API
- Построение геометрии в реальном времени с центрированием камеры
- Распознавание размеров и геометрии с чертежей
- Автоматическое исправление ошибок построения (цикл самокоррекции)
- Пошаговый режим моделирования с визуализацией каждого этапа
- Поддержка локальных нейросетей через LM Studio (без передачи данных в интернет)
- Поддержка облачных мультимодальных моделей Google Gemini

СИСТЕМНЫЕ ТРЕБОВАНИЯ
- Операционная система: Windows 10 или Windows 11 (64-bit)
- САПР: Autodesk Inventor Professional 2025
- Python: версия 3.10 или 3.11
- Для локальной работы: LM Studio с мультимодальной моделью (например, Qwen2.5-VL-7B)
- Для облачной работы: ключ Google Gemini API

УСТАНОВКА И ЗАПУСК
1. Клонируйте репозиторий или скачайте исходный код.
2. Установите необходимые зависимости командой в терминале:
   pip install -r requirements.txt
3. Убедитесь, что Autodesk Inventor 2025 запущен.
4. Запустите приложение:
   python main.py
   или запустите файл run.bat

НАСТРОЙКА СЕТЕВОЙ LLM И КУДА ВСТАВИТЬ API КЛЮЧ
Если вы хотите использовать облачную нейросеть Google Gemini вместо локальной LM Studio, вам потребуется API-ключ.
Получить бесплатный ключ можно на сайте: https://aistudio.google.com/app/apikey

Есть два способа добавления ключа:

Способ 1 (через интерфейс приложения):
1. В левой верхней панели Настройки LLM переключите выбор на Google AI Studio (Gemini).
2. В появившемся поле API-ключ вставьте ваш полученный ключ.
3. Нажмите кнопку Сохранить настройки в .env. Ключ автоматически сохранится в конфигурационный файл.

Способ 2 (через конфигурационный файл .env):
1. Откройте файл .env в текстовом редакторе в корневой папке программы.
2. Найдите строку:
   GEMINI_API_KEY=
3. Вставьте ваш ключ сразу после знака равно без кавычек и пробелов, например:
   GEMINI_API_KEY=AIzaSyD...
4. Также укажите провайдера по умолчанию:
   LLM_PROVIDER=gemini
5. Сохраните файл .env.

СТРУКТУРА ПРОЕКТА
- main.py - точка входа для запуска графического интерфейса
- src/gui.py - графический интерфейс пользователя на PySide6
- src/inventor_bridge.py - модуль взаимодействия с COM API Autodesk Inventor 2025
- src/llm_client.py - клиент для работы с LM Studio и Google Gemini
- src/drawing_parser.py - анализатор чертежей PDF, DWG, DXF и изображений
- src/config.py - управление настройками и конфигурацией
- drawings/ - папка для размещения чертежей
- tests/ - автоматические тесты компонентов
- requirements.txt - список библиотек Python
- run.bat - скрипт быстрого запуска для Windows
