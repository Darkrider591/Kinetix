# Папка для чертежей (Drawings)

Помещайте сюда ваши чертежи для распознавания и построения 3D-моделей в Autodesk Inventor 2025:
- PDF чертежи (*.pdf)
- DWG чертежи (*.dwg)
- DXF файлы (*.dxf)
- Изображения эскизов (*.png, *.jpg, *.jpeg)

Вы можете выбрать файл через кнопку в интерфейсе или скопировать файлы напрямую в эту папку.
